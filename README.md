# Tic-Tac-Toe Game 🎮

A classic, interactive Tic-Tac-Toe web game built using vanilla frontend technologies as part of my web development learning journey.

## ✨ Features
* **Two-Player Mode:** Alternates turns between **X** and **O** with distinct color styling.
* **Draw Detection:** Automatically tracks total moves and declares a draw if all boxes are filled without a winner.
* **Interactive Audio:** Sound effects trigger dynamically on valid moves.
* **Responsive Reset:** Easily reset or start a new game at any time with clean state management.

## 🛠️ Tech Stack
* **HTML5:** Structure and layout of the game grid and UI.
* **CSS3:** Custom styling, layout design, and marker themes.
* **JavaScript (ES6):** Core game logic, DOM manipulation, win-pattern validation, and event listeners.
